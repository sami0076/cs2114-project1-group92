# TaskEasy Frontend

Vite + React + TypeScript frontend for TaskEasy.

## Running it

```
cd frontend
npm install     # first time only, or after package.json 
npm run dev     # http://localhost:5173 - leave this running
```

`npm run dev` does not exit; stop it with Ctrl+C.

## Before pushing a branch

```
npm run build   # runs tsc, then builds
```
